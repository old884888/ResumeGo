## 1. 背景与目标

### 1.1 痛点

市面简历工具的套路：编辑免费、保存收费（WPS「保存需开通超会」）、导出加水印、内容上传云端存隐私隐患。用户缺的是一个**长在自己电脑里、不收钱、不套路**的简历工具。

### 1.2 目标

1. **免费且无套路**：无账号、无水印、无会员、无上传。
2. **数据 100% 本地**：所有数据存浏览器本地，永不外发。
3. **产品逻辑符合直觉**：内容与样式分离，所填即所见，所见即导出。
4. **果风（Apple 风格）UI**：留白、克制、层次、丝滑动效，编辑器本身就要好看。

### 1.3 非目标（第一版明确不做）

- 不做已有 PDF 的导入解析编辑（技术难度大、还原度难保证）
- 不做云同步、多人协作、账号体系
- 不做移动端适配（PC-first，建议视口 ≥ 1280px）
- 不内置 AI 功能（仅预留接口，见 §6.5）

## 2. 产品定位与设计原则

**定位**：一款运行在浏览器里的本地简历制作工具，面向中文求职者，覆盖「填内容 → 调样式 → 导出 PDF」完整闭环。

**设计原则**：

1. **内容与样式分离**：左栏只管填内容，右栏只管换样式，互不干扰；换模板不丢内容。
2. **所见即所得**：中间预览就是最终导出效果，同一渲染引擎，无第二套排版逻辑。
3. **本地优先**：零网络依赖，自动保存，刷新/关闭浏览器数据不丢。
4. **渐进增强**：核心闭环（编辑 + 导出）先做到最简可用，样式与智能功能逐层叠加。
5. **果风克制**：装饰服务于可读性；动效 150–350ms、全程可被打断、尊重系统减弱动态设置。

## 4. 信息架构与用户流程

### 4.1 页面结构（SPA 路由）

```
/            简历列表页
/editor/:id  编辑器
/settings    设置（外观模式 / 数据管理 / 关于）
```

### 4.2 编辑器三栏布局

```
┌────────────┬────────────────────────────┬────────────┐
│  内容表单   │        A4 实时预览          │  样式面板   │
│  (左,可滚动)│   灰底中央纸张,可缩放翻页    │ (右,可折叠) │
└────────────┴────────────────────────────┴────────────┘
     280px              弹性自适应                260px
```

- 左栏：基本信息 + 各分区表单，分区折叠面板，顶部有简历名与保存状态。
- 中栏：纸张居中，底部悬浮缩放控件与页码；纸张带柔和投影。
- 右栏：模板缩略选择、主题色色板、字体 / 密度 / 边距分段控件、显示开关。
- 顶栏（通栏）：返回列表、简历名（可改）、保存状态点、导出 PDF 主按钮。

### 4.3 主流程

1. 打开应用 → 简历列表页（首次使用自动生成一份示例简历，让用户 3 秒内看到成品效果）。
2. 新建 / 点击卡片 → 进入编辑器。
3. 左栏填内容，中栏即时变化；右栏换模板、调颜色。
4. 点「导出 PDF」→ 浏览器打印预览（边距选「无」、勾选「背景图形」）→ 另存为 PDF。首次导出时有一步引导图示。
5. 全程自动保存，直接关页面也不丢。

### 4.4 导出技术路径

- 页面常驻一个隐藏打印根节点 `#print-root`，与预览共用同一套模板组件渲染（无缩放、无阴影版本）。
- `@media print`：隐藏 `#app`，只显示 `#print-root`；`@page { size: A4; margin: 0 }`，纸张内边距由样式设置承担。
- 分页控制：条目、分区标题设置 `break-inside: avoid`，避免条目被拦腰截断。

## 5. 数据模型

```ts
type SectionType = 'education' | 'work' | 'project' | 'skill' | 'custom'
type Column = 'main' | 'side'          // 双栏模板下的落位

interface Resume {
  id: string                           // nanoid
  schemaVersion: 1                     // 预留迁移
  name: string                         // 列表显示名，如「Java后端-2026校招」
  createdAt: number
  updatedAt: number
  basics: Basics
  sections: Section[]                  // 数组顺序即渲染顺序
  style: ResumeStyle
}

interface Basics {
  name: string
  headline?: string                    // 求职意向，如「Java 后端开发工程师」
  photo?: string                       // dataURL，可空
  fields: KV[]                         // 电话/邮箱/年龄/城市/博客/GitHub…条数不限
}

interface KV { id: string; label: string; value: string }

interface Section {
  id: string
  type: SectionType
  title: string                        // 可改名，如「工作经历」→「实习经历」
  visible: boolean
  column: Column                       // 默认 main；双栏模板下 side 落侧栏
  items: Item[]
}

interface Item {
  id: string
  title: string                        // 公司 / 学校 / 项目名
  subtitle?: string                    // 职位 / 专业·学历 / 担任角色
  dateText?: string                    // 自由文本「2025.07 – 至今」，不做日期选择器
  location?: string
  bullets: string[]                    // 支持 **加粗** 行内语法
  link?: { label: string; url: string }
}

interface ResumeStyle {
  template: 'classic' | 'modern' | 'twocolumn'
  accent: string                       // 主题色 hex
  fontFamily: 'sans' | 'serif'
  density: 'compact' | 'normal' | 'relaxed'
  margin: 'narrow' | 'normal' | 'wide'
  showPhoto: boolean
  showIcons: boolean                   // 联系方式小图标
}
```

**存储**：`localStorage` key `pdfgo.resume.<id>`，索引 `pdfgo.index`；照片在上传时经 canvas 压缩（≤300KB）再入库。JSON 导出文件即上述结构序列化，带 `schemaVersion` 便于后续迁移。

## 6. 技术方案

### 6.1 选型

| 层 | 选型 | 理由 |
|---|---|---|
| 构建 | Vite + Vue 3 + TypeScript | 快、生态成熟、维护者熟悉 Vue |
| 状态 | Pinia | 简历文档状态 + 手搓 undo/redo |
| 路由 | Vue Router 4 | 三页面 SPA |
| 样式 | 原生 CSS + CSS Variables design tokens | **不引 UI 组件库**，果风全手搓，拒绝组件库默认味 |
| 图标 | lucide-vue-next | 线性、克制、果感 |
| 拖拽（P1） | @formkit/drag-and-drop | 轻量、零样式侵入 |
| 持久化 | localStorage + File System Access API | 导出 JSON 备份走系统保存对话框（Chromium 支持） |
| PNG 导出（P1） | html-to-image | 仅导出时使用，不影响编辑渲染 |
| PDF | 原生 print CSS 管线（§4.4） | 免费、矢量、文字可选中 |

### 6.2 代码结构

```
src/
  main.ts / App.vue
  router/
  stores/          # resumes.ts(文档集合) editor.ts(当前文档+undo栈) ui.ts
  models/          # types.ts  defaults.ts  sample.ts(示例简历)
  composables/     # useAutosave.ts useUndo.ts useZoom.ts useTheme.ts usePrint.ts
  components/
    home/          # ResumeCard.vue  NewResumeMenu.vue
    editor/        # ContentPanel.vue  PreviewPane.vue  StylePanel.vue
    preview/       # Paper.vue  templates/Classic|Modern|TwoColumn.vue  blocks/*
    ui/            # AppButton  AppInput  AppSelect  AppSwitch  AppModal  AppToast  ColorSwatch...
  print.css
```

### 6.3 撤销 / 重做

文档级快照栈：每次变更 debounce 300ms 合并连续输入后压栈，上限 100 步；简历文档体量小，JSON 快照无性能压力。比 patch/diff 方案简单可靠。

### 6.4 模板体系

每个模板是一个独立 Vue 组件，接收 `{ resume }` 渲染到 A4 纸张；模板只管排版，不持有状态。双栏模板按 `section.column` 分配左右栏，单栏模板忽略该字段——换模板永不丢数据。

### 6.5 AI 预留接口（不实现）

```ts
interface AiService {
  polishBullet(text: string, ctx: ResumeContext): Promise<string>
  optimizeForJD(resume: Resume, jd: string): Promise<Suggestion[]>
  generateSummary(resume: Resume): Promise<string>
}
```

Service 注册位留空；未来实现时约定：用户自带 API Key，请求由浏览器直发模型厂商，不经任何中间服务器。

## 7. UI 设计规范（果风）

### 7.1 色彩

| Token | 亮色 | 深色 |
|---|---|---|
| bg 页面背景 | #F5F5F7 | #1C1C1E |
| surface 表面 | #FFFFFF | #2C2C2E |
| text-primary | #1D1D1F | #F5F5F7 |
| text-secondary | #6E6E73 | #A1A1A6 |
| text-tertiary | #AEAEB2 | #6E6E73 |
| accent 交互蓝 | #0A84FF | #0A84FF |
| danger / success / warning | #FF3B30 / #30D158 / #FF9F0A | 同左 |

- 所有语义色走 CSS 变量，深色模式整套翻转；**纸张恒白，不参与主题翻转**。
- 分隔线 hairline：`1px solid rgba(0,0,0,.06)`（暗色 `rgba(255,255,255,.08)`）。
- 主题色板（简历强调色 8 选 1）：藏蓝 `#1D4ED8`、墨黑 `#1D1D1F`、松绿 `#15803D`、酒红 `#B91C1C`、紫 `#6D28D9`、橙 `#C2410C`、青 `#0E7490`、灰金 `#A16207`。

### 7.2 字体

- UI 字体栈：`-apple-system, "SF Pro Text", "PingFang SC", "Microsoft YaHei", sans-serif`，UI 基准 13px。
- 纸张 sans：`"PingFang SC", "Microsoft YaHei", "Noto Sans SC"`；serif：`"Songti SC", SimSun, "Noto Serif SC"`。
- 字号阶梯：11 / 12 / 13 / 15 / 17 / 20 / 24 / 32。
- 不捆绑字体文件，走系统字体降级；预览与导出同引擎渲染，所见即所得不受跨机字体差异影响。

### 7.3 形态

- 圆角：6 / 10 / 14 / 20（控件 / 卡片 / 弹窗 / 纸张容器）。
- 阴影（双层柔影）：`0 1px 2px rgba(0,0,0,.04), 0 8px 24px rgba(0,0,0,.06)`。
- 间距：4px 基准网格；栅格 12 列仅用于列表页。
- 纸张：编辑内 794×1123px（96dpi A4），`transform: scale` 缩放显示；导出物理 210×297mm。
- 毛玻璃：顶栏与浮层 `backdrop-filter: saturate(1.8) blur(20px)` + 半透明背景。

### 7.4 动效参数

- 时长：微交互 150ms / 标准 250ms / 页面级 350ms。
- 缓动：标准 `cubic-bezier(0.25, 0.1, 0.25, 1)`；弹层 spring `cubic-bezier(0.34, 1.56, 0.64, 1)`。
- 全局尊重 `prefers-reduced-motion`，命中时动效降为直接切换。

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| 浏览器打印分页偏差 | `@page margin:0`，留白由纸张内边距承担；条目 `break-inside: avoid`；导出引导图示（边距选「无」、勾选「背景图形」） |
| Windows 与 macOS 字体不一致 | 系统字体栈降级；预览与导出同引擎，本机所见即所得恒成立 |
| localStorage 容量上限（~5MB） | 照片上传即压缩（canvas，≤300KB）；提供 JSON 一键备份引导 |
| 浏览器兼容 | 主推 Chrome / Edge（Chromium）；进入页面时检测非 Chromium 内核给出提示条 |
| 开发环境中文路径 | 工作区路径含中文，已验证 Git Bash 读写正常；Vite 默认配置可运行，出问题再迁移 workspace |
